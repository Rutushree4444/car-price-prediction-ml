# Car Price Prediction Using Machine Learning

## Project Overview

This project uses Machine Learning techniques to predict the price of a car based on different features such as engine capacity, number of seats, car type, and other price-related attributes.

The project demonstrates a complete Machine Learning workflow, including data loading, data preprocessing, exploratory data analysis, model training, prediction, and evaluation.

## Objectives

- Analyze the car price dataset.
- Perform data preprocessing and cleaning.
- Explore relationships between car features and price.
- Train Machine Learning regression models.
- Predict car prices using the trained model.
- Evaluate model performance using regression metrics.

## Dataset

The dataset contains information about different cars and their prices.

### Features

- Car Name
- Minimum Price
- Maximum Price
- Price Range
- Engine Capacity (CC)
- Number of Seats
- Number of Variants
- Car Type
- Ex-Showroom Price
- RTO
- Insurance
- Other Charges
- On-Road Price

## Machine Learning Workflow

1. Import required libraries
2. Load the dataset
3. Inspect the dataset
4. Clean and preprocess the data
5. Perform Exploratory Data Analysis (EDA)
6. Select features and target variable
7. Split the dataset into training and testing sets
8. Train Machine Learning models
9. Make predictions
10. Evaluate model performance
11. Visualize the results

## Evaluation Metrics

The model performance is evaluated using regression metrics such as:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
